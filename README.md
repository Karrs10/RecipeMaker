# RecipeMaker
DESCRIPTION
The Recipe & Calorie Calculator is a concept for developing a Java application which allows users to create, manage, and save recipes while calculating their total calorie content. The application will use Java Swing components within a JFrame graphical user interface (GUI). Users will be able to enter recipe information, including ingredients, quantities, and calorie values, through text fields. Information can be submitted by pressing the Enter/Return key or clicking a Save button. The application will automatically convert measurements as needed to calculate each ingredient'sz calorie content and the total calories for the recipe. Users will also be able to enter the number of servings and a customizable serving description, such as "1 tablespoon" or "about 3 cookies." The application will calculate and display both the total calories for the entire recipe and the calories per serving. An optional Advanced Calculator button will allow users to enter nutritional information from ingredient labels, including protein, carbohydrates, and fat per serving. The application will use these values to estimate the macronutrient content of recipes and individual servings.
